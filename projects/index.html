Projects

Real time data pipelines, backend systems, and tools that handle repetitive work.

Lightning Data Pipeline

A real time pipeline that decodes Blitzortung's compressed WebSocket feed, stores the lightning strikes in PostgreSQL, and serves them through a FastAPI REST API. Built with Python, PostgreSQL, FastAPI, and Docker. Source code ↗

Job Application Automation

AI agents drive a browser through job applications from start to finish, with a separate handler for Greenhouse, Workday, Oracle, and Ashby. Built with Python and Chrome DevTools. Source code ↗

RideWatch

Tracks how reliable public transit is by comparing GTFS-Realtime feeds against published schedules. It has a live vehicle map and delay history for each stop. Built with Go, PostgreSQL, and MapLibre. Source code ↗
