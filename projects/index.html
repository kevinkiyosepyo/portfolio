03 / Transit data

Personal project

RideWatch

A public-transit reliability tracker that compares GTFS-Realtime feeds against published schedules. It combines a live vehicle map with stop-level reliability history and delay notifications.

  • Reconciles repeated and out-of-order feed updates into a consistent record.
  • Archives raw data for replay and versions schedules to preserve historical meaning.
  • Uses precomputed reliability summaries rather than aggregating every request.

Go · PostgreSQL · GTFS-Realtime · MapLibre
